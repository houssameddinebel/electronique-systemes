
ES Électronique & Systèmes — Espace Étudiant

A student-focused educational platform for the Électronique & Systèmes program at the Faculty of Sciences, Agadir (FSA), Morocco.

🌐 Live Demo: Open the Website

📖 About the Project

ES Électronique & Systèmes is a web-based student resource platform designed to make academic materials easier to access and organize.

The project provides a centralized space for students to find educational resources, follow their academic work, and navigate useful information related to their studies.

✨ Features

📚 Course Materials: Access course-related educational resources.

📝 TDs: Find tutorial exercises and practice materials.

🔬 TPs: Organize and access practical-work resources.

📅 Timetables: Access academic schedule information.

🤖 AI Assistant: An interface for an AI-powered student assistant.

✅ Completed Work: A dedicated section for completed academic work.

🌙 Theme Toggle: Switch the interface theme using the available theme control.

💾 Local Data: The website indicates that its educational resources are stored locally.

🎯 Project Goals

Simplify access to academic resources.

Organize learning materials in one place.

Improve the student experience through a centralized interface.

Make useful educational information accessible online.

Explore the integration of AI-assisted student tools.
